# 🛡️ Linux 云服务器安全加固标准操作手册

> **适用系统**：Ubuntu / Debian（针对 CentOS/RHEL 部分命令有备注）
> **核心原则**：先建立新通道，再关闭旧通道；永远保留一个备用连接（如阿里云 VNC 控制台）以防锁死。

---

## 🚦 阶段一：云控制台网络层配置（阿里云/腾讯云等）
在登录服务器之前，先在网页控制台完成初步防护。

1. **安全组规则收紧**：
   * **SSH 端口 (22)**：建议将授权对象从 `0.0.0.0/0` 改为**你的固定公网 IP**（若 IP 不固定则保持默认）。
   * **Web 端口 (80/443)**：对 `0.0.0.0/0` 开放。
   * **其他高危端口**：绝对不要对公网开放（如 3306 数据库、6379 Redis 等）。
2. **配置自动快照策略**：
   * 路径：控制台 -> 存储与快照 -> 自动快照策略。
   * 建议：每天凌晨执行，保留 7 天，并**绑定到实例**。

## 👤 阶段二：账号与 SSH 权限体系加固
**登录方式**：使用 root 账号登录，或通过云控制台 VNC 进入。执行过程中**绝对不要关闭当前终端窗口**。

### 1. 创建普通用户并赋予 sudo 权限
```bash
# 1. 创建用户（将 codepencil 替换为你想要的名字）
adduser codepencil

# 2. 将用户加入 sudo 组（Ubuntu/Debian）
usermod -aG sudo codepencil
# 备注：如果是 CentOS/RHEL，请将 sudo 替换为 wheel

# 3. 验证提权是否成功
su - codepencil
sudo whoami  # 输入密码后应返回 root
```

### 2. 禁用 root 的 SSH 密码登录
切回 root 权限，修改 SSH 配置文件：
```bash
# 1. 备份配置文件（好习惯）
sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak

# 2. 编辑配置文件
sudo nano /etc/ssh/sshd_config
```

在文件中找到 `PermitRootLogin` 这一行，修改为：
```ini
PermitRootLogin no
```
*保存退出（Ctrl+O -> Enter -> Ctrl+X）。*

```bash
# 3. 重启 SSH 服务生效（注意 Ubuntu 服务名为 ssh，CentOS 为 sshd）
sudo systemctl restart ssh
```

### 3. 生死验证（关键！）
**保持当前窗口不关**，新开一个终端：
*   **测 root**：`ssh root@服务器IP` （应报错 Permission denied，证明加固成功）。
*   **测普通用户**：`ssh codepencil@服务器IP` （应能正常登录，证明退路还在）。

## 🚫 阶段三：部署 Fail2ban 动态防御
既然保留了普通用户的密码登录，必须配合 Fail2ban 防止暴力破解。

### 1. 安装
```bash
sudo apt update
sudo apt install fail2ban -y
```

### 2. 配置本地规则
不要直接改 `jail.conf`，创建本地覆盖文件：
```bash
sudo nano /etc/fail2ban/jail.local
```

粘贴以下配置（失败 3 次封禁 1 天）：
```ini
[sshd]
enabled = true
port = 22
filter = sshd
# Ubuntu 24.04+ 默认使用 systemd journal，无需指定 logpath
maxretry = 3
bantime = 86400
findtime = 600
```
*保存退出。*

### 3. 启动与验证
```bash
# 重启服务
sudo systemctl restart fail2ban

# 查看服务状态（确保是 active (running)）
sudo systemctl status fail2ban

# 查看 sshd 的防护状态
sudo fail2ban-client status sshd
```

## 🔄 阶段四：系统更新与漏洞修补

### 1. 开启自动安全更新
```bash
sudo apt install unattended-upgrades -y
sudo dpkg-reconfigure --priority=low unattended-upgrades
# 在弹出的界面中选择 <Yes>，按回车
```

### 2. 执行一次全面更新与清理
```bash
# 刷新软件源并全量升级
sudo apt update
sudo apt upgrade -y

# 处理被系统保留（held back）的核心包（如 cloud-init）
sudo apt install --only-upgrade cloud-init
# 或者使用更激进的：sudo apt full-upgrade -y

# 清理无用依赖
sudo apt autoremove -y
```

### 3. 检查是否需要重启
```bash
[ -f /var/run/reboot-required ] && echo "需要重启" || echo "不需要重启"
# 若提示需要重启，执行 sudo reboot，稍后重连即可
```

## 📦 附：Docker 网络最佳实践提示
如果你后续使用 Docker，请勿使用默认的 `bridge` 网络。
*   **原则**：为不同的应用栈创建独立的自定义 bridge 网络，实现容器间的网络隔离。
*   **命令**：`docker network create my-app-net`
*   **启动容器时**：指定 `--network my-app-net`，同网络内容器可直接通过容器名 DNS 解析通信，不同网络默认隔离。
